# ARCHITECTURE 测试文档（列表/行内标记在编辑态的可见性与几何）

这个文件是 2026-11-05 用户实测「点进列表项后仍显示原文、画面跳动」的复现夹具。
文件名固定为 `ARCHITECTURE.md`（用户要求：测试文档一律用这个文件名）。

- 偏移只有一份换算：`document/offset.rs` 把 comrak 的（行，列）与全局字节偏移互转；
  展示层再显式换到 UTF-16。中文与 Emoji 的错位都出在这里。
- 分块不按字节或空行切：`blocks` 在既有 AST 上取顶层块区间，代码围栏、列表、引用都能跨行。
- 安全选项从第一行代码起就开着：`to_comrak()` 里绝不出现 `unsafe = true`。
- 长任务不占主线程：`open_document` / `reload_document` 是 `async`，且持锁 → 放锁 → 再持锁。

## 嵌套与有序列表

1. 第一项：有序列表的编号在编辑态也不该露出 `1. `。
2. 第二项：
   - 嵌套无序项 `nested`。
   - 再嵌套一层：
     1. 三级有序项。
3. 第三项。
