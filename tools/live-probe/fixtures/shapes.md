# 组合形状夹具（编辑 ＋ 渲染的交叉压力）

这一份只给 `block-harness.js` 提供**当前其它夹具没有组合过的形状**：引用里嵌列表与围栏、
带对齐的表格（单元格里有行内代码与强调）、硬换行与反斜杠换行、
setext 标题、HTML 块、强调嵌套、任务项里的行内代码与链接、中文与 emoji 混排。
⛔ 不作为阅读排版判据的唯一来源，也⛔ 不替代 `blocks.md` / `tasks.md` / `edges.md`。
⚠️ 每条形状都单独成块并附一句说明，红的时候能一眼定位是哪条形状。

## 强调嵌套

这一段有 ***粗斜***、有 **粗体里的 `code`**、有 *斜体里的**粗体***，还有 ~~删除线~~。

⚠️ 斜体收尾的星号**前面不能有空格**（CommonMark 的 flanking 规则，comrak 与 Lezer 都认）；
带空格时两边都渲染成字面星号，而 `B{i}-3c` 的独立 oracle 仍会把星号藏掉 ⇒ 判据假红
（2026-11-12 实测，记在本文末的注释里）。⛔ 别为了"看起来自然"往收尾星号前加空格。
