# 任务项：一次点击只该动一个字节

这一份夹具专喂 `design/0051` 的 **V 段**。它必须同时含三种行：

1. **真任务项**（`- [ ]` / `- [x]` / `- [X]`）——comrak 会物化 `TaskItem`，载荷里有区间；
2. **看着像但不是**（`- []`、`- [ ]` 后面没空格、表格里的 `[ ]`、围栏里的 `- [ ]`）
   ——它们**一个条目都不该出现**（`INV-TASK-05`），而屏幕上看起来几乎一样；
3. **普通列表项**（`- 普通项`）——方框本来就不该有。

- [ ] 待办一：中文在方框**后面**（列要按 UTF-16 码元算，⛔ 不是字节）
- [x] 已完成二
- [X] 大写的已完成三
- 普通列表项：**没有**方框
- [] 看着像但不是（同一张列表里，方括号里是空的）
  - [ ] 嵌套子项四（先序排第三，⛔ 不是按层级）
  - [ ] 嵌套子项五

1. [ ] 有序列表里的任务六
2. 有序列表里的普通项

> - [x] 引用里的任务七

- [] 看着像但不是（方括号里是空的）
- [ ]后面没有空格（同样不是任务项）

| 列一 | 列二 |
|---|---|
| [ ] 表格里的方括号 | 不是任务项 |

```text
- [ ] 围栏里的方括号也不是任务项
```

最后一段：上面每一个方框都只该翻转**它自己**那一个字节——行数、行尾、两侧文字一个都不动。
